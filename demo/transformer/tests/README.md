# Verification scope

Run `npm test` from the project root. Tests check the actual published-source
adapters, strict input parsing, exact source-excerpt identity, source attribution
on unchanged bytes only, preserved original measures/turns, scoped identifiers,
explicit import-time semantics, chain and external checkpoint behavior, UI
exports and packaged download integrity.

The separate profile explorer uses complete synthetic importer-observation
carrier fixtures generated by the companion Python implementation. Its tests
compare the data module with the packaged JSON, inspect extension equality,
retain source/host time distinctions, and assert isolation from the empirical
aggregate. This does not run an LRS, a Caliper endpoint or certification suite.

The old five synthetic branded mapping fixtures were removed. They proved
internal consistency with self-authored contracts, not vendor compatibility.
The new research adapters do not claim unchanged Python mapping parity.

`python scripts/verify_public_sources.py --fetch` separately checks excerpts
against independently retrieved pinned original files. Source hashes prove
byte identity to those releases; they do not independently validate original
participant data, transcripts, learning effects or pedagogical classifications.

Keep transcript/session counts, participant summaries, and transcript turns
separate in interpretation. Never create hint sequences from summary conditions,
turn tutor speech into proven effective help, or fabricate absolute event times.
