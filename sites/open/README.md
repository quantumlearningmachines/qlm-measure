# open.quantumlearningmachines.com

One static page listing everything QLM publishes openly or offers free: tools for districts, free tools, open datasets, trained models, SDKs and code, the Learnlog Internet-Draft, and papers. Each item shows the license its source states; items that state none say "Free to read" or "Free to use".

Deployed on Vercel as the `open-site` project. To redeploy from this folder:

```
vercel deploy --prod
```

Before changing an entry, load its link and read its license where it is published. The footer's "checked on" date should match the last full link check.
