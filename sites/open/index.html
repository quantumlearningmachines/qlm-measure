  • qlm-map-classifier

    Labels a K-12 math student response with the misconception it shows, from 39 grouped categories. It catches most misconceptions, and about half of what it flags is wrong.

Internet-Drafts

Open proposals we've submitted to the IETF. Each is an individual Internet-Draft, not an approved standard.

  • Learnlog Assistance Capture Profile and Optional Event File Representation

    A proposed open format for recording AI help in learning. It keeps each stage of help apart, and it never turns "not recorded" into "none." Revision 03.

    IETF DatatrackerAbout Learnlog
    IETF Trust

  • Signed Handoff Context for Agentic Dialogs

    A way to carry verifiable, signed context when one AI agent hands a task to another, so the next agent can check what came before. Revision 00, posted October 26, 2026.

    IETF Datatracker
    IETF Trust
